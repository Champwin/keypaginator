键盘翻页助手 · 设置

按键触发时自动点击页面上的「下一页 / 下一章 / Next」等翻页链接。改动即时生效，无需重启浏览器。

1. 总开关

关闭后所有站点都不响应按键。

2. 触发按键

多个按键用英文逗号分隔。支持修饰键组合，写法：Alt+KeyN、Ctrl+ArrowRight、Shift+Space。单键可直接写 ArrowRight、j、Period。

注意：在输入框、文本域、可编辑区域内打字时不会触发，可放心使用单字母键。

3. 行为

0 = 不做提示直接点击
开启后按住按键会连续翻页，容易翻过头

4. 阅读配色

为长时间看小说设定舒服的底色与字色。部分站点把配色写进 CSS 变量，一旦设成「深底 + 没设字色」，正文会回落纯黑导致整页漆黑；本模块既提供配色预设，也内置对比度守护兜底。

启用阅读配色
对所有站点生效（含普通网页，配色会覆盖全站底色）
主机名写 example.com 即匹配其全部子域名；每行一个。关闭「对所有站点生效」时，只对这里列出的站点应用配色。
背景 文字
WCAG AA 正文标准 4.5；守护发现配色低于此值会自动纠正
对比度守护（配色不可读时自动纠正，杜绝黑底黑字）
顺带清除站点的脏配色（治本，但会重置你在站点里调过的背景色）
—

本扩展不预置任何站点名单。若某站出现「底色设深后文字变黑」的不可读情况，把该站加入上方「作用站点」即可启用配色与对比度守护。

5. 站点自定义选择器

自动识别不准的站点，在这里手写 CSS 选择器（优先级最高）。主机名写 example.com 即可匹配所有子域名。

主机名下一页选择器上一页选择器

示例：#next_chapter、a.next:not(.disabled)、.pager a:last-child

6. 禁用站点

这些站点上完全不响应（例如在线文档、视频站，它们自己也用方向键）。一行一个，或用逗号分隔。

7. 备份 / 恢复

导出为 JSON 保存，换电脑时导入即可。
